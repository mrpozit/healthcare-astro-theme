# ICRA page images

Кожна сторінка має власну папку.

## Імена файлів

- `hero.jpg` - головне фото сторінки
- `photo-01.jpg`, `photo-02.jpg`, `photo-03.jpg` - одиночні фото в порядку появи на сторінці
- `carousel-01/01.jpg`, `carousel-01/02.jpg`, ... - фото першої каруселі
- `carousel-02/01.jpg`, ... - друга карусель, якщо вона потрібна

## Формати

Використовуємо тільки два базові співвідношення сторін:

- `5:3` - горизонтальне фото
- `3:5` - вертикальне фото

Композиція сторінки може бути вільною, але нові випадкові формати фото не додаємо.

## Важливо

На сторінці `social` блок про підлітків залишається без фотографій дітей або підлітків.
