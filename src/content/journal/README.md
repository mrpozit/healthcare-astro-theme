# Как добавить новую запись в «Життя ICRA»

1. Скопируйте папку `_template` целиком.
2. Назовите копию `YYYY-MM-DD-short-name`, например `2026-09-20-new-meeting`.
3. Откройте `index.md` и измените заголовок, дату, тип, excerpt и текст.
4. Если нужен cover, положите `cover.jpg` в эту же папку и добавьте во frontmatter строку `cover: "./cover.jpg"`.
5. Другие фотографии положите рядом как `01.jpg`, `02.jpg` и вставляйте в Markdown: `![Описание](./01.jpg)`.
6. Пока запись не готова, оставьте `draft: true`.
7. Для публикации поставьте `draft: false`.
8. Commit/push в `main`. Vercel автоматически пересоберёт сайт.

Больше нигде запись прописывать не нужно. Astro сам найдёт папку, создаст `/blog/<имя-папки>/` и поставит запись в ленту по дате.

Допустимые `type`: `event`, `library`, `research`, `project`, `field-note`, `process`, `social`, `womens-space`, `icra`, `update`.

`featured: true` делает запись кандидатом на крупный первый материал. Если таких несколько, первой будет самая свежая. Если таких нет, крупной становится самая свежая опубликованная запись.

Для связи с существующим материалом Библиотеки можно добавить `relatedLibraryItem: "/library/slug"`. Для внешней ссылки можно использовать `externalUrl: "https://..."`.
