# Как добавить новую запись в «Життя ICRA»

1. Скопируйте папку `_template` целиком.
2. Назовите копию `YYYY-MM-DD-short-name`, например `2026-09-23-new-meeting`.
3. Откройте `index.md` и измените заголовок, дату, тип, excerpt и текст.
4. Обложка всегда называется `cover.jpg` и лежит рядом с `index.md`. В шаблоне уже есть `cover: "./cover.jpg"`.
5. Обычные фотографии называем `01.jpg`, `02.jpg`, `03.jpg` и так далее.
6. `draft: false` публикует запись. `draft: true` временно скрывает её.
7. Commit/push в рабочую ветку. Vercel пересоберёт сайт.

Astro сам найдёт опубликованную запись и добавит её в «Життя ICRA».

## Instagram

Во frontmatter:

```yaml
instagramUrl: "https://www.instagram.com/reel/XXXXXXXXXXX/"
```

Лучше использовать чистую ссылку на Reel без служебных параметров после `?`.

## YouTube

Поддерживаются обычные ссылки YouTube, `youtu.be`, Shorts и embed-ссылки:

```yaml
youtubeUrl: "https://www.youtube.com/watch?v=XXXXXXXXXXX"
```

Видео появится встроенным плеером в записи.

## Галерея

Положите фотографии рядом с `index.md` и перечислите их во frontmatter:

```yaml
gallery:
  - "./01.jpg"
  - "./02.jpg"
  - "./03.jpg"
```

Галерея выводится компактной сеткой. Клик по фотографии открывает её в полном размере. Если фотографию нужно поставить в конкретное место текста, используйте обычный Markdown:

```md
![Опис фотографії](./01.jpg)
```

## Связь записи с разделом сайта

Во frontmatter можно указать один основной раздел:

```yaml
relatedSection: social
```

Допустимые значения:

- `about` → Про нас
- `library` → Бібліотека
- `services` → Консультації
- `women-space` → Жіночий простір
- `social` → Суспільна діяльність
- `life` → Життя ICRA
- `contact` → Контакти

Внизу записи появится ссылка на выбранный раздел.

Для ссылки на конкретный материал Библиотеки используйте:

```yaml
relatedLibraryItem: "/library/slug"
```

Для произвольной ссылки внутри текста:

```md
[текст посилання](/library/)
```

Для внешней ссылки:

```md
[текст посилання](https://example.com)
```

Допустимые `type`: `event`, `library`, `research`, `project`, `field-note`, `process`, `social`, `womens-space`, `icra`, `update`.

`featured: true` делает запись кандидатом на крупный первый материал в ленте.
