# Бібліотека ICRA

Один матеріал = одна папка.

Приклад:

```
src/content/library/akatsia/
  index.md
  cover.jpg
  file.pdf
```

## Що класти в папку

- `index.md` — текст і службові поля матеріалу. Основний формат для сайту: Markdown.
- `cover.jpg` — вертикальна книжкова обкладинка. Рекомендоване співвідношення 2:3.
- `file.pdf` — необов'язково. Версія для завантаження або окремий оформлений матеріал. QR-код на сайт можна вбудовувати прямо в PDF.
- додаткові зображення можна називати `01.jpg`, `02.jpg` і далі.

Не потрібно редагувати сторінку каталогу вручну. Коли колекцію повністю переведемо на content layer, сайт братиме дані з цих папок автоматично.

Для нового матеріалу скопіюйте папку `_template`, перейменуйте її латиницею і заповніть `index.md`.
